# 四合成

> 1910 年，枫树冲农家子多乐进城当学徒，头一回看见纱厂的“两本账”。<br>
> 他拉上小沅、阿野、小满合股，在旧铺板上刻下“四合成”三个字。<br>
> 字号做大了，人却一个个散掉：一个早死，一个出局，一个下南洋。<br>
> 登顶那年他摸了摸刻痕，想起刻字那晚谁说了句“歪就歪”。

**标签**：【商战+年代+群像+理想与代价】

全书 121 章｜约 27.5 万字｜单章 2200–2500 字
